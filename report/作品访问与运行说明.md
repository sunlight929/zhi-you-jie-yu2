## 一、项目简介

本平台聚焦中国**大学生**与**中老年**两大重点人群的抑郁症筛查,集成:

- **PHQ-9 / CES-D 国际临床金标准量表**(Kroenke 2001 / CHARLS 采用版本)
- **三模型机器学习集成**(随机森林 + 梯度提升 + 逻辑回归,AUC 0.91-0.94)
- **DeepSeek 大语言模型 AI 心理健康助手**(大赛附件 4 合规清单内)
- **真实匿名用户测试反向验证**(382 份样本,Pearson r = 0.905,p < 0.001)
- **全国 34 省级行政区抑郁热力图**(自然资源部审图号 GS(2016)1600 号)
- **天津 16 区县本地化决策支持**

## 三、本地启动(备份方案)

如在线访问不便,可在本地一键启动:

```bash
# 1. 解压代码包
unzip "知忧解郁 代码.zip"
cd 知忧解郁

# 2. 安装依赖(Python ≥ 3.10)
pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env,填入 DeepSeek API Key(如需 AI 助手功能)

# 4. 启动平台
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。

## 五、技术架构

- **数据层**:NHANES 5,068 + Mendeley 682 + 中国学生 5,000 + 中老年 4,000 + 真实用户测试 382
- **模型层**:scikit-learn 三模型集成 + 量表融合(60% 量表 + 40% ML)
- **AI 层**:DeepSeek 大模型(OpenAI 兼容协议)
- **应用层**:Streamlit 多页面 Web 应用,六大功能模块
- **数据持久化**:Supabase(PostgreSQL),真实用户测试数据云端实时回流
- **部署**:Streamlit Cloud 公网部署,已上线运营
