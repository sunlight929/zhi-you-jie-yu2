## 一、项目简介

本平台聚焦中国两大重点人群（**在校大学生** 与 **中老年群体**）的抑郁症筛查需求，整合公开人群健康调查数据，构建抑郁风险**多维度可视化分析**与**机器学习早期识别**能力，集成 **DeepSeek 大模型 AI 心理健康助手**，并面向天津本地化场景提供**精神卫生资源决策支持**。平台已**部署上线**，通过**真实匿名用户测试**反向验证模型可行性。

> 🌐 **在线访问（已部署）**：https://zhi-you-jie-yu.streamlit.app

### 核心特性

- 📊 **多维数据全景大屏**：人口学、生活方式、心理社会因素 360° 画像
- 🩺 **国际/国内临床金标准量表**：完整 9 项 PHQ-9（Kroenke 2001，18-44 岁）+ 10 项 CES-D（CHARLS 采用版本，45+）
- 🤖 **三模型集成预测**：随机森林 + 梯度提升 + 逻辑回归，AUC 0.91-0.94
- 🔍 **可解释性分析**：每个预测都附带特征贡献分解，自杀念头题项独立预警
- 🧠 **临床三合一评估**：标准量表 + 风险因素 + ML 模型，与三甲医院筛查流程一致
- 💬 **DeepSeek AI 心理健康助手**：大赛合规清单内大模型，基于评估结果个性化情感支持 + 就医引导 + Q9 危机干预护栏
- 📈 **真实用户测试验证**：云端部署 + 匿名数据回流（Supabase），Pearson 相关分析验证模型与量表一致性
- 🗺️ **合规中国地图**：全国 34 省热力图，审图号 GS(2016)1600 号（自然资源部标准地图服务）
- 🏙️ **天津本地化决策支持**：16 区县抑郁检出率 + 精神卫生资源配置对比 + 权威数据源链接
- 📥 **真实公开数据接入**：内置 NHANES PHQ-9 数据下载脚本（CDC 公开，零门槛）

## 二、快速开始

### 2.1 环境要求

- Python 3.9+
- 推荐内存 ≥ 4 GB
- 浏览器（Chrome / Edge / Safari 等）

### 2.2 安装依赖

```bash
pip install -r requirements.txt
```

### 2.3 准备数据与模型

**方式 A：使用演示数据（最快路径）**
```bash
# 生成演示数据集（5000 学生 + 4000 中老年 + 16 区县）
python data/data_generator.py
python models/train_models.py
```

**方式 B：接入真实公开数据（推荐用于答辩）**
```bash
# 下载 + 转换 NHANES 真实 PHQ-9 数据（CDC 公开，无需注册）
python data/download_real_data.py --source nhanes --convert
# 生成的 data/real/nhanes_phq9_processed.csv 包含约 5000 条真实样本
```

**方式 C：进一步接入 Kaggle 学生心理健康数据集**
```bash
# 需先注册 Kaggle 账号 + 配置 ~/.kaggle/kaggle.json
pip install kaggle
python data/download_real_data.py --source kaggle
```

### 2.4 启动平台

```bash
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`，从左侧导航进入各功能模块。
