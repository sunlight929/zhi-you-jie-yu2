## 一、平台概述

### 1.1 适用人群

| 用户类型 | 主要用途 |
|---|---|
| 个人用户 | 抑郁自评、了解自身风险因素、获取就医引导 |
| 学校心理老师 | 学生群体筛查、风险分层、识别需关注个案 |
| 社区卫生工作者 | 老年抑郁筛查、健康教育素材 |
| 公共卫生决策者 | 区域抑郁分布对比、精神卫生资源配置参考 |

### 1.2 平台六大功能模块

1. **🏠 首页**：项目介绍、KPI 总览
2. **📡 数据驾驶舱**：霓虹大屏 + 全国 34 省抑郁检出率热力图（合规审图号 GS(2016)1600）+ 9 组联动组件
3. **📊 数据全景**：人群抑郁画像
4. **🔍 风险因素分析**：核心风险因子识别
5. **🧠 智能评估**：交互式抑郁风险评估 + **DeepSeek AI 心理健康助手**
6. **📈 用户测试数据**：真实用户测试覆盖 + 模型可行性验证（Pearson 相关）
7. **🏙️ 天津决策支持**：区域分析与资源建议
8. **📚 关于项目**：技术架构与参考文献

## 二、安装与启动

### 2.1 安装步骤

```bash
# 1. 解压项目压缩包
# 2. 进入项目目录
cd 知忧解郁

# 3. 安装依赖
pip install -r requirements.txt

# 4. 生成数据和模型（首次运行需要）
python data/data_generator.py
python models/train_models.py

# 5. 启动平台
streamlit run app.py
```

### 2.2 浏览器访问

**方式一(推荐)· 在线访问**:平台已部署上线,直接浏览器打开或微信扫码即可,无需安装:
```
https://zhi-you-jie-yu.streamlit.app
```

**方式二 · 本地启动**:启动后浏览器会自动打开 `http://localhost:8501`,也可手动复制此地址到浏览器。

### 2.3 关闭平台

在终端按 `Ctrl + C` 即可。

- **全国 34 省级行政区抑郁检出率热力图**(ECharts 渲染):鼠标悬停查看各省具体检出率;地图下方标注**审图号 GS(2016)1600 号**(自然资源部·标准地图服务),符合《公开地图内容表示规范》

### 3.2 📊 数据全景大屏

#### 学生群体 Tab
- KPI 行：样本量、抑郁人数、检出率、平均 PHQ-9
- 抑郁分级饼图（甜甜圈型）
- 性别×分级堆叠柱状图
- 年级 / 专业类型抑郁检出率
- 生活方式箱型图（睡眠、学业压力、屏幕时长）
- 可展开查看原始数据样本

#### 中老年群体 Tab
- 类似学生群体，关键指标改为 ADL、慢性病、社会参与等

#### 双群体对比 Tab
- 核心指标对比表
- 检出率对比柱状图
- 关键发现总结

### 3.3 🔍 风险因素分析

#### 学生群体 Tab

  - 蓝色 → 负相关（反向变化）

#### 模型性能 Tab

### 3.4 🧠 智能评估（核心功能）

#### 操作流程
1. 选择群体类型（学生 / 中老年）
2. 填写四部分信息：
   - 基本信息（年龄、性别、年级 / 教育等）
   - 生活方式（睡眠、运动、屏幕时长）
   - 心理社会因素（学业 / 经济压力、社会支持等）
   - 既往史（家族史、慢性病、童年逆境等）
3. 点击「🔬 开始评估」
4. 查看结果：
   - 风险仪表盘（绿黄橙红四档）
   - 三模型概率详情
   - 风险等级与简要说明
   - 个性化贡献因素图
   - 分层干预建议
5. 使用 **AI 心理健康助手**(见下)进行追问交流

#### 💬 DeepSeek AI 心理健康助手

提交评估后,页面会出现 AI 心理健康助手对话框（完整版在左侧栏,移动端测试版在主页面）:
- 基于**大赛附件 4 合规清单内的 DeepSeek 大模型**构建
- 自动读取你的量表分数、ML 风险概率、Top 风险因子作为上下文
- 可追问"我现在该怎么调整作息""天津哪家医院能挂号"等问题,获得**个性化情感支持 + 生活方式建议 + 本地就医引导**
- 提供推荐问题快捷入口,点击直接发送
- **临床安全护栏**:若 PHQ-9 第 9 题(自伤念头)阳性,AI 每次回复都会优先推送 24h 心理援助热线 400-161-9995
- ⚠️ AI 助手仅供参考,不替代医生诊断

#### 风险等级解读
| 等级 | 概率范围 | 颜色 | 建议 |
|---|---|---|---|
| 低风险 | <30% | 🟢 绿 | 维持当前状态，每年自检 |
| 轻度关注 | 30-50% | 🟡 黄 | 自我调节 + 校园 / 单位资源 |
| 中度风险 | 50-70% | 🟠 橙 | 2 周内寻求专业评估 |
| 高风险 | ≥70% | 🔴 红 | 立即就医 |

#### 重要提醒
- ⚠️ 本工具**不能替代**临床诊断
- ⚠️ 中度及以上风险务必寻求专业医师评估
- ⚠️ 出现自伤念头请立即拨打热线 **400-161-9995**

### 3.4c 📈 用户测试数据（模型可行性验证）

该模块面向项目方/评委,实时展示真实匿名用户测试数据:
- **测试覆盖总览**:累计测试人数、学生/中老年分布、反馈完成率
- **样本人口学**:年龄、性别分布
- **量表分数分布**:PHQ-9 / CES-D 直方图 + 检出率(对照文献)
- **模型可行性验证散点图**:量表归一化分数 vs ML 综合风险概率 + Pearson 相关系数,验证 ML 模型与临床金标准量表的一致性
- **用户主观评价**:量表清晰度、结果可信度、AI 助手满意度、推荐意愿(NPS)
- 数据由 Supabase 云数据库实时同步,可一键导出 CSV

> 用户测试通过 `?mode=test` 测试模式收集,全程匿名(仅会话级 UUID,不含姓名/电话/IP),符合《个人信息保护法》。

## 四、典型使用场景

### 场景 A：大学生自我评估（5 分钟）

```
1. 打开平台（在线 zhi-you-jie-yu.streamlit.app 或本地）→ 进入「智能评估」
2. 选择"学生 / 一般成人（18-44 岁，适用 PHQ-9）"
3. 如实填写所有问卷项
4. 点击「提交评估」，查看仪表盘
5. 与 AI 心理健康助手交流，获取个性化建议
6. 根据风险等级决定下一步行动
```

### 场景 B：高校心理老师群体筛查（30 分钟）

```
1. 接入学校心理普查脱敏数据（替换 data/student_depression.csv）
2. 重新训练模型：python models/train_models.py
3. 进入「数据全景」查看群体画像
4. 进入「风险因素分析」识别本校高风险因子
5. 导出高风险学生名单（基于模型概率排序）
6. 制定一对一谈话计划
```

### 场景 C：社区卫生服务中心老年筛查（10 分钟 / 人）

```
1. 老人到访社区卫生服务中心
2. 工作人员协助填写「智能评估」（中老年）
3. 现场查看风险等级
4. 根据建议进行：
   - 低风险：年度复测
   - 关注：健康教育材料发放
   - 中高风险：联系家庭医生 / 转诊精神科
```

### 场景 D：天津公共卫生决策（30 分钟）

```
1. 进入「天津决策支持」页面
2. 查看 16 区县抑郁检出率排序
3. 识别高检出率 + 低资源区
4. 参考"政策建议"制定资源配置方案
5. 联动本地求助资源进行专项行动
```

## 五、常见问题（FAQ）

**Q1：评估结果显示高风险，是不是说明我有抑郁症？**
A：不是。本工具是**筛查辅助**而非诊断工具。结果仅提示"统计意义上具有抑郁倾向的可能性较高"，最终诊断需精神科医生通过临床访谈确定。建议尽快就医评估。

**Q2：填写问卷时不确定某项怎么选？**
A：所有题目均为最近 1-2 周的总体感受，按"最贴近的状态"选择即可。轻微误差不影响整体风险判断。

**Q3：可以匿名使用吗？数据会被收集吗？**
A：**完全匿名**。个人自评时不收集姓名、电话、IP、设备等任何身份信息。用户测试模式下,仅收集匿名问卷答案与反馈打分(以会话级随机 UUID 关联,关闭浏览器即无法追溯到本人),用于系统改进与学术研究,符合《个人信息保护法》(PIPL)。可放心使用。

**Q4：可以多次评估观察变化吗？**
A：完全可以。建议间隔 1-2 周进行一次自评，观察情绪与生活变化。

**Q5：平台支持手机使用吗？**
A：支持。平台已部署上线(zhi-you-jie-yu.streamlit.app),**手机微信扫码或浏览器即可访问**,测试模式已做移动端适配(单列布局、选项卡片化、按钮加大)。评委版完整大屏在 PC / 平板上体验更佳。

**Q6：如何替换为我们机构的真实数据？**
A：将真实数据按 `data/student_depression.csv` 列名整理，替换该文件后重新运行 `python models/train_models.py` 即可。详细字段说明见 `docs/技术文档.md`。

**Q7：评估时网络是否必需？**
A：量表打分与机器学习模型推理均在本地/服务端完成。仅 **AI 心理健康助手对话**需要联网(调用 DeepSeek 大模型);若不使用 AI 助手,评估全程可离线完成。
