# 用户手册

> 知忧·解郁 — 多源数据驱动的抑郁症风险识别与决策支持平台
> 版本 v1.0

---

## 一、平台概述

### 1.1 适用人群

| 用户类型 | 主要用途 |
|---|---|
| 个人用户 | 抑郁自评、了解自身风险因素、获取就医引导 |
| 学校心理老师 | 学生群体筛查、风险分层、识别需关注个案 |
| 社区卫生工作者 | 老年抑郁筛查、健康教育素材 |
| 公共卫生决策者 | 区域抑郁分布对比、精神卫生资源配置参考 |

### 1.2 平台五大模块

1. **🏠 首页**：项目介绍、KPI 总览
2. **📊 数据全景**：人群抑郁画像
3. **🔍 风险因素分析**：核心风险因子识别
4. **🧠 智能评估**：交互式抑郁风险评估
5. **🏙️ 天津决策支持**：区域分析与资源建议
6. **📚 关于项目**：技术架构与参考文献

## 二、安装与启动

### 2.1 安装步骤

```bash
# 1. 解压项目压缩包
# 2. 进入项目目录
cd 知忧解郁

# 3. 安装依赖
pip install -r requirements.txt

# 4. 生成数据和模型（首次运行需要）
python data/data_generator.py
python models/train_models.py

# 5. 启动平台
streamlit run app.py
```

### 2.2 浏览器访问

启动后浏览器会自动打开 `http://localhost:8501`。
也可手动复制此地址到浏览器。

### 2.3 关闭平台

在终端按 `Ctrl + C` 即可。

## 三、各页面操作详解

### 3.1 🏠 首页

- 顶部紫蓝色横幅展示项目名称与定位
- 四个 KPI 卡片：总样本量、整体抑郁检出率、模型最佳 AUC、覆盖区县数
- 近 10 年趋势折线图：可悬停查看具体数值
- 四大模块导航卡片
- 底部技术架构与合规声明

### 3.2 📊 数据全景大屏

#### 学生群体 Tab
- KPI 行：样本量、抑郁人数、检出率、平均 PHQ-9
- 抑郁分级饼图（甜甜圈型）
- 性别×分级堆叠柱状图
- 年级 / 专业类型抑郁检出率
- 生活方式箱型图（睡眠、学业压力、屏幕时长）
- 可展开查看原始数据样本

#### 中老年群体 Tab
- 类似学生群体，关键指标改为 ADL、慢性病、社会参与等

#### 双群体对比 Tab
- 核心指标对比表
- 检出率对比柱状图
- 关键发现总结

### 3.3 🔍 风险因素分析

#### 学生群体 Tab
- 核心变量相关性矩阵（红蓝渐变热力图）
  - 红色 → 正相关（同向变化）
  - 蓝色 → 负相关（反向变化）
- 三模型特征重要性对比
- 逻辑回归系数表（显示效应方向）
- 临床风险因子总结

#### 中老年群体 Tab
- 类似学生群体

#### 模型性能 Tab
- 三模型性能指标表
- 双群体性能可视化对比
- 模型选型说明

### 3.4 🧠 智能评估（核心功能）

#### 操作流程
1. 选择群体类型（学生 / 中老年）
2. 填写四部分信息：
   - 基本信息（年龄、性别、年级 / 教育等）
   - 生活方式（睡眠、运动、屏幕时长）
   - 心理社会因素（学业 / 经济压力、社会支持等）
   - 既往史（家族史、慢性病、童年逆境等）
3. 点击「🔬 开始评估」
4. 查看结果：
   - 风险仪表盘（绿黄橙红四档）
   - 三模型概率详情
   - 风险等级与简要说明
   - 个性化贡献因素图
   - 分层干预建议

#### 风险等级解读
| 等级 | 概率范围 | 颜色 | 建议 |
|---|---|---|---|
| 低风险 | <30% | 🟢 绿 | 维持当前状态，每年自检 |
| 轻度关注 | 30-50% | 🟡 黄 | 自我调节 + 校园 / 单位资源 |
| 中度风险 | 50-70% | 🟠 橙 | 2 周内寻求专业评估 |
| 高风险 | ≥70% | 🔴 红 | 立即就医 |

#### 重要提醒
- ⚠️ 本工具**不能替代**临床诊断
- ⚠️ 中度及以上风险务必寻求专业医师评估
- ⚠️ 出现自伤念头请立即拨打热线 **400-161-9995**

### 3.5 🏙️ 天津决策支持

- KPI：覆盖区县数、总样本量、平均检出率、最高检出率区
- 区县检出率水平柱状图（按检出率排序）
- 资源-检出率散点图（点大小 = 老龄化程度）
- 区县风险分级与干预建议表
- 平台政策建议（4 大方向）
- 本地求助资源（医院 + 热线）

### 3.6 📚 关于项目

- 项目背景（疾病负担、人群特征、资源现状）
- 系统架构（ASCII 图）
- 技术栈表
- AI 工具协作策略
- 数据来源与参考文献
- 数据合规与伦理
- 团队介绍
- 项目链接与致谢

## 四、典型使用场景

### 场景 A：大学生自我评估（5 分钟）

```
1. 启动平台 → 进入「智能评估」
2. 选择"学生（17-26 岁）"
3. 如实填写所有问卷项
4. 点击评估，查看仪表盘
5. 阅读个性化建议
6. 根据风险等级决定下一步行动
```

### 场景 B：高校心理老师群体筛查（30 分钟）

```
1. 接入学校心理普查脱敏数据（替换 data/student_depression.csv）
2. 重新训练模型：python models/train_models.py
3. 进入「数据全景」查看群体画像
4. 进入「风险因素分析」识别本校高风险因子
5. 导出高风险学生名单（基于模型概率排序）
6. 制定一对一谈话计划
```

### 场景 C：社区卫生服务中心老年筛查（10 分钟 / 人）

```
1. 老人到访社区卫生服务中心
2. 工作人员协助填写「智能评估」（中老年）
3. 现场查看风险等级
4. 根据建议进行：
   - 低风险：年度复测
   - 关注：健康教育材料发放
   - 中高风险：联系家庭医生 / 转诊精神科
```

### 场景 D：天津公共卫生决策（30 分钟）

```
1. 进入「天津决策支持」页面
2. 查看 16 区县抑郁检出率排序
3. 识别高检出率 + 低资源区
4. 参考"政策建议"制定资源配置方案
5. 联动本地求助资源进行专项行动
```

## 五、常见问题（FAQ）

**Q1：评估结果显示高风险，是不是说明我有抑郁症？**
A：不是。本工具是**筛查辅助**而非诊断工具。结果仅提示"统计意义上具有抑郁倾向的可能性较高"，最终诊断需精神科医生通过临床访谈确定。建议尽快就医评估。

**Q2：填写问卷时不确定某项怎么选？**
A：所有题目均为最近 1-2 周的总体感受，按"最贴近的状态"选择即可。轻微误差不影响整体风险判断。

**Q3：可以匿名使用吗？**
A：本平台**不收集任何个人身份信息**，所有数据均为本地处理，不上传服务器，可放心使用。

**Q4：可以多次评估观察变化吗？**
A：完全可以。建议间隔 1-2 周进行一次自评，观察情绪与生活变化。

**Q5：平台支持手机使用吗？**
A：当前为 Web 端，手机浏览器可访问，但大屏体验在 PC / 平板上更佳。后续版本将适配移动端。

**Q6：如何替换为我们机构的真实数据？**
A：将真实数据按 `data/student_depression.csv` 列名整理，替换该文件后重新运行 `python models/train_models.py` 即可。详细字段说明见 `docs/技术文档.md`。

**Q7：评估时网络是否必需？**
A：所有计算均在本地完成，**不需要联网**。
