## 📌 发送建议

| 时段 | 群组 | 用哪一版 |
|---|---|---|
| **第一天上午** | 班级群、寝室群 | 同学群版本（轻松） |
| **第一天下午** | 朋友圈 | 朋友圈版本 |
| **第一天晚上** | 家人群 | 家人版本 |
| **第二天** | 单独私聊一些重点朋友 | 任意 |
| **第三天** | 给老师发 | 专业版 |
| **第五天** | 未填同学催回 | 催回版本 |

**目标节奏**：
- D1-D2: 收 30-40 份（同学 + 朋友）
- D3-D4: 收 20-30 份（家人 + 朋友圈传播）
- D5-D7: 催回未填,目标累计 60-75 份

---

## ⚠️ 注意事项

1. **不要在群里反复发**（会被嫌烦),每个群最多 2 次（首发 + 催回）
2. **私聊比群发效果好**——重点关注的朋友单独私聊更容易让对方认真填
3. **填完的人记得感谢**——发个红包或 表情包,维持关系
4. **避免凌晨发**(晚上 22:00 后发,白天没人看到反而效果差)
5. **微信扫码识别有时会卡**——可以提示用户「长按二维码识别」
