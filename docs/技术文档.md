    ↓

    ↓

    ↓
RF.predict_proba(x) → p_rf
GB.predict_proba(x) → p_gb
LR.predict_proba(x_scaled) → p_lr
    ↓

    ↓
风险等级映射 + 建议生成
    ↓

## 四、模型设计细节

### 4.1 特征工程

#### 学生群体（16 个特征）
- 数值型：年龄、睡眠、运动、压力评分、屏幕时长
- 二元：性别_女、家族史、童年逆境、慢性病、吸烟、饮酒
- 顺序：年级_大四、年级_研究生（哑变量）

#### 中老年群体（14 个特征）
- 数值型：年龄、慢性病数、ADL、睡眠、社会活动、子女联系、BMI
- 二元：性别_女、独居、城乡_农村、吸烟、饮酒
- 顺序：教育年数（0/6/9/12/15）、收入_数值（0/1/2）

### 4.2 超参数选择理由

| 参数 | 值 | 理由 |
|---|---|---|
| `n_estimators=400` (RF) | 400 | 足够大保证稳定，未过拟合 |
| `max_depth=10` (RF) | 10 | 控制过拟合 |
| `min_samples_leaf=8` | 8 | 防止过拟合到稀有样本 |
| `class_weight="balanced"` | balanced | 抑郁阳性是少数类，需提升召回 |
| `n_estimators=200` (GB) | 200 | 配合 0.05 学习率，收敛充分 |
| `learning_rate=0.05` | 0.05 | 经验值，平衡精度与训练时间 |
| `max_iter=1000` (LR) | 1000 | 保证收敛 |

### 4.3 集成策略

使用**简单平均**而非加权平均，原因：
- 三模型 AUC 接近，加权增益有限
- 简单平均易于解释
- 鲁棒性更好（对单一模型异常预测不敏感）

如需更精细的集成，可改用 logits 空间平均或堆叠（stacking）。

### 4.4 可解释性方法

当前采用**逻辑回归系数 × 标准化特征**的局部贡献分解：

```python
contribution_i = β_i * z_i
```

**优势**：
- 计算成本极低（O(d)）
- 输出可直接被医生理解（系数 > 0 → 升高风险）
- 不需要额外依赖

**局限**：
- 仅捕获 LR 模型的线性效应
- 不能解释 RF / GB 的非线性交互

**升级路径**：替换为 SHAP（已在 requirements 中预留）：

```python
import shap
explainer = shap.TreeExplainer(rf)
shap_values = explainer.shap_values(x_row)
```

### 4.5 类不平衡处理

学生群体抑郁阳性率约 30%，中老年约 15%。采用三种方法兼用：
1. **`class_weight="balanced"`**：模型层面赋予少数类更高权重
2. **F1 + Recall 优先**：在阈值选择上偏向召回
3. **`stratify=y` 分层抽样**：训练-测试集保持类别分布一致

医疗筛查场景"宁可错召、不可漏诊"，召回率优先级 > 精确率。

## 附录：关键代码片段

### A.1 三模型集成预测

```python
def predict_with_explain(bundle, x_row):
    rf = bundle["rf"]
    gb = bundle["gb"]
    lr = bundle["lr"]
    scaler = bundle["scaler"]
    features = bundle["features"]

    x = x_row[features]
    rf_p = rf.predict_proba(x)[0, 1]
    gb_p = gb.predict_proba(x)[0, 1]
    x_scaled = scaler.transform(x)
    lr_p = lr.predict_proba(x_scaled)[0, 1]
    final = (rf_p + gb_p + lr_p) / 3

    contributions = (lr.coef_[0] * x_scaled[0]).tolist()
    return {"final_proba": final, "contributions": contributions, ...}
```
